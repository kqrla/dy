# roadmap

## short term

- add more concept pages (second brain, digital gardens, graphic organizers) as standalone guides instead of linking to the concepts index
- add search functionality (client-side, using a pre-built index)
- add breadcrumb navigation on subpages
- ensure all guide pages have consistent structure (intro, content, note/callout)
- add meta descriptions and open graph images for every page
- audit accessibility (keyboard nav, screen reader, color contrast)

## mid term

- add user authentication via supabase auth
- add bookmarking so users can save guides to their profile
- add a reading progress indicator on guide pages
- add a dark mode toggle that also switches icon colors (some icons are hard to see in dark mode)
- add print stylesheets for guide pages
- add a sitemap and rss feed
- migrate the vercel adapter to a more portable setup or document the switch

## long term

- add user-submitted content (community guides, corrections)
- add interactive circuit simulators embedded in electronics pages
- add spaced repetition flashcard decks tied to guide content
- add collaborative note-taking (real-time via supabase)
- add a mobile app or pwa with offline support
- add analytics to understand which guides are most useful
- internationalization (at least spanish and japanese)
